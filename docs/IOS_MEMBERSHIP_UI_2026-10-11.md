# 国内 iOS 主会员页面修复（2026-10-11）

当前路由 /subscription 指向 SubscriptionPageV2。原页面没有查询当前账号会员状态，固定显示 SVIP、399 元等价格，月付/家庭卡不能选择，购买固定发送颐养年付，且包含英文推荐标记、支付宝单次购买说明及未实现的帮助入口。

本批改为页面加载、手动刷新及应用恢复前台时查询核心 /subscription/status。付费、免费、加载、查询失败分开显示；请求代次阻止较早响应覆盖较新结果。查询失败不从本地推测权益。价格使用 StoreService 已加载的 ProductDetails.price，缺少商品价格时禁用购买；月付、年付、家和年付选择分别发送准确 SKU。购买启动返回 true 仅显示请求已提交，不修改会员状态。恢复购买回调触发服务端状态刷新，不直接赋予本地会员。

移除固定金额、英文推荐、支付宝说明和未经当前数据支持的宣传权益。页面使用中文、可滚动布局、明确的刷新与恢复入口，适配窄屏及大字号。

- 三项真实 Flutter 渲染截图测试通过，已逐图视觉核对免费、付费、查询失败三种状态，390×1000。测试显式加载中文和 Material Icons 字体。
- 修改文件及两个测试文件的 Flutter 静态分析无问题。
- 截图在 evidence/2026-10-11-ios-membership-ui/。其中价格、账号状态、有效期均为测试夹具，不是当前商店报价、真实用户数据或生产联调结果。

## 未完成边界

本批修改国内 iOS 主会员页，未宣称 Android/Web 同类问题已修复。Android 订阅服务仍可能将查询失败回退成免费状态，需要后续独立修复。StoreService 恢复购买的交易确认时序、商店商品刷新和真实设备购买/恢复仍需专项验收；本批只验证页面通过服务端状态决定显示，不是商店交易全链路验收。没有新增后端变更，后端最近全量结果仍为 3416 通过、387 失败、17 跳过，并非本批重跑结果。四产品整体未达到完整上线验收。
