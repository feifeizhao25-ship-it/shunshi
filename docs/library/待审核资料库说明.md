# 顺时·官方资料库（待审核）

本目录说明新增的“官方资料库”：条目、来源、审核流程和怎么在预览里看到它。

## 现状

- 共 12 条，**全部是“待审核”**。每条都只收 A 级来源：作者读过官方原文全文（或明确写出读到的范围），并写明出处、文号、发布/生效日期、读取日期和状态（现行 / 征求意见稿 / 已废止 / 待核实）。
- **默认不会显示任何条目**：页面显示“资料正在审核中”，入口也会隐藏。审核通过前，这些条目不会出现在正式界面，也不会被 AI 检索或引用。
- 预览（仅开发和审核用）：编译或运行时加 `--dart-define=SHOW_PENDING_LIBRARY=true`。

## 文件

- `lib/presentation/pages/library/reference_library_page.dart`：列表、搜索、分类和状态筛选、详情页、审核门禁
- `lib/presentation/pages/library/shunshi_reference_library.dart`：顺时的文字和入口卡片
- `assets/library/reference_entries_v1.json`：条目数据
- 入口：养生馆首页下方的“官方资料库”卡片，路由 `/reference-library`（android-cn 和 ios-cn 都有）

## 审核流程

由顺时的专家审核（沿用现有专家审核流程）：逐条对照原文，通过后把该条的 `review_status` 改成“已审核”，条目才会出现。不要在代码里改审核门禁，也不要批量改成“已审核”。
