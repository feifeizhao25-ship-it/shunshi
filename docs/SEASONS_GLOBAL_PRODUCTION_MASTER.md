## Product Definition
- Name: SEASONS
- Position: AI Calm Lifestyle Companion
- Core: "Live in rhythm with nature"
- NOT: medical diagnosis, therapy, medication advice, crisis handling replacement

## Core Experience Principles
- calm, minimal, low-pressure, emotionally safe, premium, repeatable

## Target Users
- 25-45 urban, high stress, sleep issues, like self-improvement but not hard-core

## 15 Required Modules
1. Onboarding (5-step, 90s, Calm-style)
2. Home (Daily Insight + 3 Gentle Suggestions + AI Chat Entry)
3. AI Companion (calm, concise, emotionally safe, not preachy)
4. Seasons (hemisphere-aware, ritual-focused)
5. Library (breathing, stretch, tea rituals, sleep, reflection)
6. Reflection (mood/energy/sleep + note, no scoring)
7. Audio (guided breathing, wind-down, sleep soundscape)
8. Profile/Settings/Privacy

10. Notifications
11. Memory & Privacy
12. Recommendation
13. Share

15. Analytics & Experimentation

## AI Architecture
- GPT: daily conversational, short practical
- Claude: emotionally nuanced, reflection, sensitive companion
- Gemini: weekly summaries, structured synthesis, long-context
- Router: intent → safety → prompt → model → validate → audit

## Safety Levels
- Level 1: normal support
- Level 2: distress support
- Level 3: crisis risk → safe mode (no upsell, no deepening)

## Memory Types
- preference, habit, rhythm, reflection theme, support style
- Default limited, explicit control, can clear all, can turn off

## Tech Stack
- Client: Flutter + Riverpod + GoRouter + Dio
- Backend: Python FastAPI + PostgreSQL + Redis + Vector DB
- Cloud: AWS (CloudFront, API Gateway, ECS, RDS, ElastiCache, S3)

## Phases
- Phase 1 (4-6 weeks): Onboarding, Home, Chat MVP, Basic Seasons, Sub skeleton, AI Router MVP
- Phase 2 (4-6 weeks): Library, Reflection, Memory, Safety hardening, Analytics, Paywall experiments
- Phase 3 (4-6 weeks): Audio, Privacy/export/delete, Family prebuild, App Store assets, Full regression, AWS prod
- Phase 4 (2-4 weeks): Beta, Experiment tuning, Conversion tuning, Safe mode tuning, Launch
