# 国内版顺时上线对照（2026-10-23）

对照仓库内 PRD、上线清单和部署文档。主人的外部文档包还没到，到了以后按同一张表补行。国际版（SEASONS）不在本轮修改范围。

状态：已接通 / 本轮修好 / 要人完成 / 未挂载的旧页面。

## 已接通（本分支并入 main 之后仍成立）

- 在售只有年付：内容订阅 ¥399、会员 ¥888。家和不能下单，已购用户权益保留。家庭人数注册表是 5 人（含购买人），可绑定 4 位。
- 中成药剂量接口不挂载。模型输出过滤功效词和处方式剂量。
- 部署脚本探 `/healthz`，成功词与后端一致。生产缺 JWT、CORS 或 PostgreSQL 地址时拒绝启动。
- 支付宝 / 微信回调按验签和订单金额入账，对不上就拒绝。

## 本轮修好

- 支付宝商品列表不再把停售的月付和家和列成可买商品。新订单不能用停售 SKU 向支付宝下单。
- 会员公开档位和对比表只留免费、内容订阅、会员，价格写成「元/年」。家和详情仍说明 5 人，并标明不在售。
- 订阅商品接口带上「年」和真实额度说明，不再让客户端把年付显示成「365天」或「基础功能」。
- 管理后台套餐页：权益如果是对象不再整页报错；停售档显示「已停售」，不按 ¥99/月 展示。
- 体质结果页不再用本地 `is_subscribed` 假装付费解锁。完成测试就能看到调理建议。真正付款不会写这个本地标记，所以原来的锁会把已付款用户也挡住。
- 茶饮、情绪、运动页去掉「升级会员解锁……」的横幅。这些内容本来就能看，会员权益里也没有单独的解锁项。
- 国内 iOS 首页、食谱、穴位和今日计划里的「排毒 / 利尿消肿 / 增强免疫」改成和安卓一样的日常说法。
- 冷启动脚本和 `seed_db.py` 不再写入这些功效词。知识库检索（关键词和语义）在返回给用户前会替换掉同一类词。辟谣页仍保留原词，用来说明「排毒」为什么不能当功效宣传。

## 要人完成（代码侧已留模板，不能代做）

来源：`docs/PRODUCTION_EXTERNAL_BLOCKERS_2026-08-27.md`、`docs/DEPLOYMENT_GUIDE.md`、`docs/LAUNCH_CHECKLIST.md`、`backend/.env.example`。

- 备案、域名和 HTTPS：`api` 域名、证书、DNS。不要把 `shunshi.ai` 指到本仓库。
- 生产密钥：`SHUNSHI_DATABASE_URL`、`SHUNSHI_JWT_SECRET`、`ADMIN_JWT_SECRET`、`ADMIN_PASSWORD_HASH`。不要把 `JWT_SECRET` 和 `SHUNSHI_JWT_SECRET` 配成两把不同的钥匙。
- 国内模型：至少配置 `SHUNSHI_DEEPSEEK_API_KEY` 或 `SHUNSHI_SILICONFLOW_API_KEY`。若走自建网关，再配 `SHUNSHI_MODEL_ROUTER_URL`。密钥只放环境，不进仓库。
- 短信：`SHUNSHI_SMS_PROVIDER_URL` 与令牌。没配时验证码接口 503。
- 支付宝商户：`ALIPAY_APP_ID`、`ALIPAY_SELLER_ID`、应用私钥、支付宝公钥、HTTPS 通知地址。没配齐时不能收款。
- 微信支付：商户号、证书序列号、APIv3 密钥、平台公钥、通知地址。
- Apple / 应用商店：开发者账号、商品 `com.shunshi.content.yearly` 与 `com.shunshi.member.yearly`、真机沙盒。商店验单目前不把收据解析当成已付款。
- 集群：单副本，先备份旧数据卷再发版。GitHub `KUBE_CONFIG` 只给 `shunshi` 命名空间。
- 上线后抽查：注册登录、对话、¥399/¥888 沙箱回调、导出和注销。
