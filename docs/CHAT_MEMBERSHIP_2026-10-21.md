# 顺时国内聊天会员显示修复

基于 fe565422，修改 Android/iOS 国内实际路由 ChatPage，未改国际版及后端。

## 已发现与修复

现行 backend/app/main.py 注册 app.routers.subscription，状态由 services/membership_status.py 提供：data 内为 plan/is_active，tier 在外层。聊天页误读 data.tier != free，缺失字段导致免费账户也显示会员。现在严格验证 success、plan、is_active，以及免费/付费状态一致性；未知字段或接口失败显示待查询，提供重试，不假定免费或已开通。请求连接及会员响应等待限制10秒，页面销毁后不更新状态。

状态接口不提供 limit/remaining，原界面默认10次并本地递减无事实依据，已移除伪额度与本地次数阻断，保留后端聊天API额度执行。免费显示免费版，付费显示会员，异常显示状态待查询。升级提示不再宣称额度用尽或所有套餐都包含家庭权益。待后续接通真实用量查询后才能展示剩余额度。

Android Flutter 14项通过：新增2项契约测试、4档实际ChatPage组件测试、失败重试1项，加原聊天恢复7项。以Dio适配器返回按后端结构编写的测试数据，不是真实会员API/数据库/支付。旧字段逻辑在免费用户页面反例中失败，修复后通过。静态分析新解析器/测试无问题，差异空白检查通过。日志在同名evidence目录。

iOS同步代码和测试，因锁定依赖缓存未齐，本轮未运行iOS组件测试。无浏览器/真机截图，不将组件测试冒充用户所需完整UI验收。
