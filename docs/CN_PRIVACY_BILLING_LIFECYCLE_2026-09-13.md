# 国内隐私页与支付数据生命周期修复

## 本轮结果

- 核心账户导出增加本人国内付款、退款申请记录，包含退款原因和待处理状态。字段使用白名单，不输出商户密钥或渠道交易流水；同时验证订单与申请的用户归属。
- 账户删除后，旧令牌不能继续访问账户导出、支付宝订单查询或退款申请接口。此处只覆盖列出的入口，不代表所有旧接口均已完成令牌撤销改造。
- 注销响应报告实际保留的付款、退款申请记录数量，明确注销不等于退款完成。没有删除金融交易证据，也没有把当前保留行为宣称为已完成留存合规；留存期限、其他历史数据清理与后续退款处理仍需落实。
- 国内 iOS/Android 隐私页移除测试网站导出、无认证的错误删除路径及仅弹成功提示的记忆清除。统一使用配置中的 API 地址及当前登录令牌，调用真实导出、注销和清空记忆接口。
- 导出展示真实 JSON 并提供复制按钮，不再声称已保存文件。注销及记忆清除只有收到明确的 `deleted=true` 才按成功处理；失败给出中文提示。
- iOS 设置页原“删除账户”仅清本地偏好的入口改为进入真实隐私数据页，移除不对应实际执行范围的删除承诺。

## 验证

后端完整回归 **3527 passed、7 skipped、72 warnings，139.36 秒**，日志 `/tmp/shunshi-billing-lifecycle-full.log`。新增账户支付生命周期 3 项回归，既有注销回归改为直接核对核心数据库已删除，同时验证旧令牌无法导出，避免将拒绝访问当作数据删除证据。

国内 iOS、Android 各新增 3 项 Flutter 控件测试并通过，覆盖导出等待真实响应、未确认清空不能显示成功、注销先确认且等待后端结果。两个隐私页及本轮修改的 iOS 设置页静态检查无问题。仓库完整性、移动网络 HTTPS 与 API 地址/版本契约门禁通过。
