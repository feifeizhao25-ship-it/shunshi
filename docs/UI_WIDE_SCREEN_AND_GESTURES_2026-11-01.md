# 宽屏、平板、折叠屏与手势规范（2026-11-01，补 X12）

此前所有文档只有断点（Tailwind、375/768/1280）和大字号 200%，没有宽屏最大宽度、平板布局、折叠屏、手势规则，
测试 N06 因此看到"宽屏被拉满"。本文件是各产品共用的最低规范；各产品可以更严，不可以更松。
最适合用户的版式优先：手机端与网页端不要求一致，但必须满足下面每一条。

## 1. 窗口尺寸等级（按窗口宽度，不按设备型号）
| 等级 | 宽度 | 布局 |
|---|---|---|
| 紧凑 | < 600 dp / px | 单栏；底部导航 ≤ 5 项；表格改卡片列表；弹窗用底部抽屉 |
| 中等 | 600–1023 | 单栏居中或"列表+详情"双栏；导航改侧边栏图标栏（折叠屏展开、平板竖屏） |
| 宽 | ≥ 1024 | 侧边栏 + 内容区；内容区必须有最大宽度（见 §2） |
| 超宽 | ≥ 1920 | 同"宽"，内容区居中，两侧留白；不得把一行文字或一张图表拉到整屏 |

## 2. 最大宽度（宽屏不得拉满）
- 阅读正文、聊天、表单、设置页：内容列最大 **720 px**（顺时、SEASONS、见己等阅读类产品的老年大字模式 **640 px**，行长 ≤ 45 个汉字 / 75 个英文字符）。
- 卡片网格：最大 **1200 px**，列数随宽度 1→2→3，不超过 4 列，卡片最小宽 280 px。
- 数据面板（新能源、分发侠后台）：最大 **1440 px**；表格可在容器内横向滚动，但图表和 KPI 卡仍受 1440 px 限制。
- 全宽只允许：顶部栏、侧边栏、整页背景、全屏地图/画布。
- 实现：Web 用容器 `max-width` + `margin-inline:auto`；Flutter 用 `ConstrainedBox(maxWidth)` + `Center`；RN 用最大宽度容器并居中。
- 验收：1280、1440、1920、2560 四个窗口宽度的截图中，正文行宽不超过上表上限，且无单行超长文字。

## 3. 平板与折叠屏
- 平板竖屏按"中等"，横屏按"宽"；不得只是把手机界面放大。
- 折叠屏：用窗口尺寸等级响应展开/折叠，不假设设备方向；折叠时内容不得丢失、输入框内容与滚动位置保持。
- 避开铰链/裁切区：可点控件和正文不跨越铰链，使用系统安全区；半折叠（桌面/帐篷姿态）时上半屏显示内容、下半屏放操作区。
- 分屏/小窗：窗口宽 < 600 即回到"紧凑"布局，不出现横向滚动条。

## 4. 手势
- **任何功能都不能只靠手势完成**：滑动删除、长按、双指缩放、下拉刷新都必须有可见按钮或菜单替代。
- 可点区域 ≥ 48 × 48 dp（老年大字模式 ≥ 56 dp），相邻控件间距 ≥ 8 dp。
- 返回：iOS 支持左缘右滑返回，Android 支持系统返回手势（预测性返回动画不得被拦截）；页面有未保存输入时，返回先确认。
- 下拉刷新：仅用于列表，刷新中有进度提示，失败有文字提示；不得与页面内横向滑动冲突。
- 横向滑动（轮播、标签页）只在明确的轮播区域响应，不抢占系统边缘手势（屏幕边缘 20 dp 内留给系统）。
- 图表与图片：支持双指缩放，同时提供"+ / − / 重置"按钮；长按显示数据提示时，也要支持点击。
- 危险操作（删除、退订、清空数据）不使用一次性手势，必须二次确认。
- 动效尊重系统"减少动态效果"；触感反馈只用于确认类操作，可关闭。

## 5. 与大字号、深色模式的关系
- 字号放大到 200% 时，内容仍受 §2 最大宽度约束，按钮文字可换行，不得被截断。
- 深色模式跟随系统；任何等级下对比度 ≥ 4.5:1（正文）/ 3:1（大号文字与图标）。

## 6. 自检清单（发布前）
1. 1280 / 1440 / 1920 / 2560 宽度下正文行宽符合 §2。
2. 600 与 1024 附近无布局跳变或横向滚动条。
3. 每个手势操作都有可见替代；关键按钮 ≥ 48 dp。
4. 折叠屏展开/折叠后输入内容与位置保留。
5. 200% 字号、深色模式各截一张。
