# 顺时国内聊天缓存隔离

基础提交5264a6fa。Android/iOS国内ChatPage和UserStorage；保留其他人的RAG改动。

## 修复

旧 chat_history / conversation_id 为全局键，缺少账户归属，显式conversationId也被旧缓存覆盖。改为按JWT sub和会话ID构成独立本地键，每个账户独立最近会话索引；刷新令牌后同一sub仍可读取，显式会话优先，未知会话为空。JWT解析仅用于本地缓存分区，不作身份验证或API授权；服务端仍负责验签及权限。

无有效subject或token与当前存储不一致时不读写历史；不从可能过时的user_info推断账户。旧版无归属记录原样保留但不自动展示/归给当前用户；不能安全自动迁移，退出清理会删除这些本地记录。新增存储失败提示，保存前快照消息/会话，切换账户后已迟到的旧请求不能写入新账户空间。

UserStorage.clear删除全部chat_v2缓存及旧全局聊天键，保留设置。清空对话等待保存后再重新加载，避免读到尚未被清空的旧数据。
