# 顺时国内访客登录与聊天失败处理

基础b157cb6d；Android/iOS国内ChatPage，未改他人RAG或后端。

## 对照现行代码的修复

app.routers.user在/api/v1/auth/guest-login返回顶层access_token，原页面读data.token导致访客凭证不保存。现按实际字段严格解析，接收等待10秒；身份未就绪时保留输入并明确提示，不发送匿名聊天。

统一POST /api/v1/chat/send，JSON message与现行app.routers.chat.ChatBody一致。原/ai/chat是服务端兼容路由，本身不等于不存在；问题在于失败后回退另一个/api/v1/chat请求，并将全部失败包装为正常AI回复、增加计数。现在每次发送只发一次请求，无自动跨接口重试。75秒接收超时明确提示结果未确认，避免假称服务端未执行。

成功必须有非空字符串text，来源必须是字符串列表；完整多段正文和全部来源保留。401/403、429、422、503/网络、无效成功响应显示持久中文错误；失败不增加chat_count、不附伪AI来源或建议卡片。输入框未被用户另行编辑时恢复原输入。切换账户后的迟到结果不追加到新账户页面。成功不再添加没有接口依据的默认建议卡片。

## 验证

Android30项Flutter本地测试通过：新增8项（访客解析、规范请求/全文、无效内容、4类失败页面、访客到完整回复页面），加此前22项。旧页面访客令牌反例失败，修复后通过；静态分析新API文件和测试无问题，git diff --check通过。日志在evidence同名目录。

Dio适配器是显式API替身；这是运行实际ChatPage的组件测试，不是实际后端/国内模型/商户或浏览器真机。iOS同步未运行组件测试（锁定依赖缓存未齐）。未新增截图，不更新截图总览为通过。
