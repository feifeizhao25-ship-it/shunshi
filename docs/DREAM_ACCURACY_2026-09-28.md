# 梦境记录准确性修复（2026-09-28）

## 问题与修改

旧实现用梦境关键词直接判断脏腑和体质，例如火对应心火、水对应肾气不足，并给出中药、剂量及穴位建议。此次删除这些未经验证的映射，保留场景描述和用户自主回顾的问题。没有把普通梦境医学化，也不按关键词推断用户情绪。

保留原 API 路径和兼容字段；organ 返回空值，remedies/acupoints 返回空数组，增加 diagnostic=false 与证据不足标记。历史列表不会重新发布旧记录保存的器官推断。旧数据库 JSON 没有破坏性改写，账号原始数据导出仍可能包含历史字段，后续展示端应明确历史内容已弃用。

原有 14 项测试逐项使用明确的登录用户，未削弱生产鉴权；另增加 16 项测试，覆盖七种梦境内容、三个参考端点、旧记录展示、匿名及跨用户访问、非法时间/类型/过长描述。输入时间按 HH:mm 校验，国内日志日期明确采用北京时间。
