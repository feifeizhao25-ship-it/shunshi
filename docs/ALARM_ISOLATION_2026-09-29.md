# 闹钟推荐隔离与输入校验（2026-09-29）

## 修复

推荐接口原来只对全局列表做浅拷贝，修改列表中的字典会改变后续用户的默认睡眠时间，重复请求还会重复追加解释。现在逐个复制推荐条目，个性化请求不会改变默认模板。

创建和更新同时校验合法 HH:mm 时间、星期和现有铃声标识；错误输入返回 422，已保存的闹钟保持不变。保留自定义闹钟类型，但限制非空和长度。登录用户可以创建、更新、删除自己的闹钟；匿名及其他用户继续被访问控制拒绝。

移除固定时辰“排毒、养肾、最佳时间”等无依据的生理效果承诺，改成可调整的示例作息。时辰标签作为传统文化说明保留，器官字段为空，明确没有诊断或治疗含义。旧 constitution 参数保留兼容，但不据此宣称医学效果。

## 验证

梦境、闹钟与访问控制组合专项 81 通过，包含新增 7 项闹钟请求隔离、非法输入和跨用户修改测试。未弱化生产鉴权。

本功能仍只是设置存储与推荐 API。本次没有证明手机系统会准时响铃、后台唤醒或通知送达，真实客户端和系统权限仍需验收。前端对空器官字段的展示仍需核实。

完整后端回归：3292 通过、422 失败、18 跳过。相比梦境修复后的结果，6 项原有闹钟失败修复、新增 7 项测试通过；未将剩余失败或跳过视为通过。代码仅推送修复分支。
