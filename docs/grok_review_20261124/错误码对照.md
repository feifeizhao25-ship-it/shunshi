# 错误码对照

接口返回给用户的句子只从 `backend/app/error_catalog.py` 取。下表与那份代码是同一张表，测试会逐条核对。国内版用中文，国际版用英文。

这不是价格、备案或语音供应商的决定。默认行为就是下面这些句子，没有单独开关。

| 错误码 | 状态码 | 什么时候用 | 国内版 | 国际版 |
| --- | --- | --- | --- | --- |
| bad_request | 400 | 请求内容有问题，但不是下面几种 | 请求内容有误，请检查后重试 | The request looks wrong. Please check it and try again. |
| not_signed_in | 401 | 没登录，或令牌根本不是登录令牌 | 请先登录 | Please sign in first. |
| session_expired | 401 | 登录过，但令牌过期、已注销，或把刷新令牌当成访问令牌 | 登录已失效，请重新登录 | Your session has expired. Please sign in again. |
| forbidden | 403 | 登录了，但没有权限 | 没有权限进行此操作 | You don't have permission to do this. |
| not_found | 404 | 没有这条内容 | 没有找到相关内容 | We couldn't find what you were looking for. |
| method_not_allowed | 405 | 这个操作不支持 | 不支持这种操作 | That action isn't supported. |
| conflict | 409 | 当前状态做不了 | 当前状态下无法完成此操作，请刷新后重试 | This can't be done in the current state. Please refresh and try again. |
| payload_too_large | 413 | 提交太大 | 提交的内容太大 | The content you submitted is too large. |
| invalid_input | 422 | 填写的内容格式不对 | 填写的内容不正确，请检查后重试 | Some of the information isn't valid. Please check it and try again. |
| rate_limited | 429 | 点得太频繁 | 操作太频繁，请稍后再试 | Too many requests. Please try again shortly. |
| quota_exhausted | 429 | 今天的对话条数用完了 | 今日对话次数已达上限，将于北京时间零点重置 | You have used today's chat messages. The limit resets once a day; Plan & usage shows when, in your own time zone. |
| quota_unavailable | 503 | 额度计数暂时读不到 | 对话额度服务暂不可用，请稍后重试 | The chat quota service is temporarily unavailable. Please try again shortly. |
| quota_misconfigured | 503 | 额度配置本身有问题 | 对话额度配置异常，请稍后重试 | The chat quota is misconfigured. Please try again later. |
| speech_unconfigured | 503 | 朗读服务没配好。不再写成「请求内容有误」 | 朗读服务尚未配置，暂时用不了 | Voice playback is not set up yet. |
| sms_unconfigured | 503 | 短信服务没配好。不假装发送成功 | 短信服务尚未配置 | Text messaging is not set up yet. |
| compliance_blocked | 200 | 内容被安全检查拦住。不写成「请稍后再试」 | 这份回答未通过安全检查，请换个问题或咨询专业人员。 | This reply didn't pass the safety check. Please ask differently or talk to a professional. |
| service_unavailable | 503 | 服务故障 | 服务暂时不可用，请稍后再试 | The service is unavailable right now. Please try again later. |
| busy | 503 | 服务忙 | 服务繁忙，请稍后再试 | The service is busy. Please try again shortly. |
| request_incomplete | 400 | 没能完成，又不属于上面几种 | 请求未能完成，请稍后再试 | The request couldn't be completed. Please try again later. |
