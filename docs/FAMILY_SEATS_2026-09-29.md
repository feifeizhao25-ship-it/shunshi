# 家庭席位持久化和到期校验（2026-09-29）

家庭席位 API 改读账号数据库的 Entitlement 和新 family_seats 表，不再依赖模块字典。添加与移除锁定账号和已有权益行，避免并发添加超额。相同成员 ID 不可重复占位；解绑可使用稳定 seat_id，保留旧 member_index 参数兼容，但不能同时提交多个选择条件。

会员过期、被移除或降级后，新增席位被拒绝，已有记录仍可查看及移除。账号导出包含席位，注销删除自有席位。该表沿用应用启动建表流程，部署需有建表/索引权限；旧进程内成员未自动伪造迁移，须由用户重新核对添加。

## 权益口径

现有家和商品写明 4 个附加席位，另一个会员模块写含主账号共 5 人，原注册表写 6 人。注册表统一为 5 人总数（主账号加 4 个附加席位），不增加原商品附加席位。补充 jiahe_monthly / jiahe_yearly 到 family 权益等级的映射，否则已购买家和套餐可能被注册表误判为免费。
