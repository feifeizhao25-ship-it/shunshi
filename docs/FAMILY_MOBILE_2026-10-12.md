# 顺时国内移动端家庭成员修复与验证（2026-10-12）

## 问题与修改
iOS 和 Android 实际路由 /family 使用 family/family_page_v2.dart。原页面每次尝试游客登录，未使用当前用户凭证，且按 data 包裹结构读取后端实际返回的扁平家庭对象；添加成员使用 relationship / age_group，与后端 relation / age 不符。读取异常被当作空家庭，缺失年龄又被后端转成 0。

本次两端使用 FamilyApi，按当前凭证读取实际接口；未登录不发请求，凭证改变后的迟到响应不用于展示。添加和删除检查服务端确认后重新读取，失败显示中文信息；删除需确认，异步结果检查页面存活状态。新增姓名、关系和可选年龄表单，服务端拒绝空白姓名、关系及非整数或不在 0–120 范围内的年龄。缺失年龄保留 null，页面显示“年龄未填写”，真实 0 岁继续显示“0 岁”。

页面使用中文关系名称，对未知关系及空姓名安全回退。明确家庭记录不等同于付费会员席位。旧模型年龄同步允许 null。
