# 登录、资料与会员状态一致性修复（2026-10-11）

旧登录和 /auth/me 使用记录库 users.is_premium、subscription_plan，付款恢复和核心权益校验使用核心 Entitlement，两者可以互相矛盾。订阅状态接口还使用 family、yiyang 等子串推导套餐，未知商品也可能显示付费权益；免费状态同时返回外层 active=false 和内层 is_active=true。

本批将三个入口统一为只读核心权益视图：有效期必须晚于当前时间，商品必须在权益注册表中登记并与已知国内套餐完整匹配。未知、过期及缺失权益均显示免费，无付费激活状态；读取故障时登录和资料返回中文 503，不假定免费。已有会员购买及授权逻辑保持独立，未使用旧标记开通权益。

资料响应保留 subscription_plan，并提供移动端模型读取的 subscription_type，两个字段保持一致。subscription_expires_at 使用 UTC ISO 日期格式，符合现有 Dart DateTime.parse；订阅状态接口保留 Unix 秒格式。核对了移动端解析代码，但没有进行本批真实 UI 截图验收。

测试覆盖 SQLite/PostgreSQL、旧标记冲突、过期、续费、未知商品名及大小写变体、各国内付费档位、其他用户权益、核心读取失败和完整 SKU 映射覆盖，并回归账号全链路、核心账号同步和订阅回调。

尚未完成：第三方登录响应、其他旧订阅接口、客户端网络错误时默认显示免费、所有宣传权益与实际配额的全面统一。本次未更改原有 features 中的套餐宣传字段，不能把会员状态修复等同于全部会员权益验收。未进行真实付款或生产部署。

专项最终结果：77 通过、2 跳过、50 条警告，22.42 秒。包括 20 个 SQLite/PostgreSQL 新场景和一个完整 SKU 覆盖校验。仓库完整性与后端部署配置检查通过。

进一步静态核对：ios-cn 当前 /subscription 路由使用 subscription_page_v2.dart；旧 subscription_page.dart 中仍有下单即显示订阅的未接线路径，不能描述为当前主路由已触发的问题。两端 UserSubscriptionStatus 原本按日期字符串解析订阅接口 Unix 秒，本批已兼容 Unix 秒与 ISO 日期；无效或越界值返回空日期。通过实际 Dart 执行 16 个模型场景，覆盖两端付费状态、异常日期、资料套餐字段。仍未进行真实设备或页面截图验收。

最终后端全量：3416 通过、387 失败、17 跳过、58 条警告，189.32 秒。失败测试标识集合与 2026-10-10 account-identity 批次完全一致；新增 21 项通过均为本批回归场景，不代表消除了既有失败。原始记录与 Dart 验证结果已保存到对应 evidence 目录。四产品整体上线验收仍未完成。
