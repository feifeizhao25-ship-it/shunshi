# 顺时国内录音失败反馈与播报状态

基础bf241e38。修改Android/iOS国内VoiceService、ChatPage及实际AIBubble。

## 本批完成

录音启动先检查权限；短录音/识别结束后的临时文件在finally清理。启动/识别失败采用中文提示，不直接显示异常堆栈。
ChatPage对识别返回null或空白显示持久错误，保留输入；成功识别完整插入文本，已有或识别过程中输入的文字保留并追加语音内容，不自动发送。启动/识别期间阻止重复启动；页面销毁取消录音，异步启动在销毁后成功也立即取消，不再对卸载页面setState。

原播报按钮只弹“正在播报”而无播放调用，已移除假成功反馈；没有onSpeak处理器时按钮禁用并提示“语音播报尚未接通”。这是准确暴露未实现状态，不是实现了播报。Android现有未被页面调用的TtsPlayerService仍有500字截断、错误吞掉等问题；未把它接入产品。iOS使用不同音频依赖，仍须分别实现。

## 证据与范围

Android35项Flutter回归通过（新增5项录音权限/空识别/全文输入/并发编辑/快速连点与卸载测试，以及之前30项）。消息组件测试新增未接通播报按钮不可点击/无假播报提示断言。第一次新增断言错把Tooltip转成IconButton而失败，已修正定位到IconButton，保留相同禁用断言后全通过。新增录音测试静态分析无问题；git diff --check通过。

VoiceInput是录音替身，未使用真实麦克风、没有实际ASR供应商请求或扬声器播放；因此服务权限/临时文件清理仅代码审查，不能记作原生硬件已验。iOS同步代码及测试，未运行组件测试。未新增浏览器/真机截图。日志见evidence同名目录。
