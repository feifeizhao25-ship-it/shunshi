# SEASONS iOS - Global Wellness Companion

SEASONS is the international version of ShunShi, an AI-driven calm lifestyle companion.

## Getting Started

```bash
flutter pub get
flutter run
```

## Build Release

```bash
flutter build ios --release
```

## Signing

Before archiving for App Store, configure:
- `DEVELOPMENT_TEAM` in Xcode project settings
- Provisioning Profile for `com.seasons.seasons`

See the root [README.md](../README.md) for full project documentation.
