# SEASONS - Global Wellness Companion

SEASONS is the international version of ShunShi, an AI-driven calm lifestyle companion based on the four seasons and seven body types.

## Getting Started

```bash
flutter pub get
flutter run
```

## Build Release

```bash
flutter build apk --release
flutter build appbundle --release
```

## Project Info

- **Bundle ID**: `com.seasons.seasons`
- **Language**: English
- **Target Markets**: Global (App Store + Google Play)
- **Backend**: http://localhost:4000/api/v1
