# 评测约定

先重现问题再改动，保留修改前基线。测试集分为开发集、未参与提示词优化的留出集、回归集。

建议扩充至每项目100个真实任务：60开发、20留出、20回归；本次仅提供8个场景种子，不能宣称已建成100例金标。

检索观察 Recall@5、MRR、来源有效率、无答案识别；生成观察可核验陈述支持率、正确拒答、任务完成率；工程观察P50/P95、调用成本、失败重试与删除隔离。

发布候选建议门槛：业务红线回归零新增失败；引用有效性100%；检索Recall@5相对基线不下降且有明确收益；P95不超过基线1.2倍、单任务成本不超过1.1倍，例外应记录收益与代价。这里是目标，不是已测成绩。

模型评委只能辅助；抽查真实证据，避免优化器接触留出答案。版本变化、固定依赖、分块策略、模型维度或权限变化均须重测。
